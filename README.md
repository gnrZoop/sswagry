## 📖 මෙය කුමක්ද?

මෙම ව්‍යාපෘතිය, **"SSW Agriculture Exam System"** හි මූලික පිටුව (Homepage) ලෙස ක්‍රියා කරයි. එහි අරමුණ වන්නේ ජපන් කෘෂිකර්ම විභාග සඳහා අවශ්‍ය සියලුම ඩිජිටල් සම්පත් එකම ස්ථානයකින් සැපයීමයි. එය අන්තර්ගත කරන්නේ:

*   **විභාග ආකෘති ප්‍රශ්න:** කෘෂිකර්ම (Crop Farming) අංශයට අදාළ ජපන් භාෂා ප්‍රශ්න.
*   **PDF බාගත කිරීම්:** සම්පූර්ණ පාඩම් පොත් සිංහල සහ ජපන් භාෂාවෙන්.
*   **අනුබද්ධ වෙබ් අඩවියක්:** විස්තරාත්මක ජපන් භාෂා පාඩම් සඳහා [sswagrysinhala](https://gnrzoop.github.io/sswagrysinhala/) වෙත සබැඳියක්.

> 💡 **ඉඟිය:** මෙය ප්‍රධාන ද්වාරය වන අතර, සවිස්තරාත්මක ජපන් භාෂා පාඩම් සඳහා **"ජපන් භාෂා පාඩම්"** බොත්තම හරහා `sswagrysinhala` උප වෙබ් අඩවියට සංචාලනය කළ හැක.

## 🚀 භාවිතා කරන ආකාරය

1.  **විභාග පුහුණුව:** "විභාග ප්‍රශ්න - Crop Farming" කොටස හරහා ජපන් භාෂා ප්‍රශ්නවලට පිළිතුරු සපයමින් පුහුණු වන්න.
2.  **PDF බාගත කිරීම:** අධ්‍යයනය සඳහා අවශ්‍ය "Crop Farming" හෝ "Livestock Farming" සිංහල PDF පොත් පහතින් බාගත කරගන්න. (ඒවායේ ප්‍රමාණය 37MB පමණ වන බැවින් බාගත කිරීමට යම් කාලයක් ගත විය හැක.)
3.  **ගැඹුරු ඉගෙනීම:** වඩාත් විස්තරාත්මකව ජපන් භාෂාව ඉගෙන ගැනීමට, **"ජපන් භාෂා පාඩම්"** (日本語) බොත්තම ක්ලික් කර වෙනම පාඩම් අඩවියට පිවිසෙන්න.
